# First Day at Maze Corp.

_Made for [Brackeys Game Jam 2025.1](https://itch.io/jam/brackeys-13)_

* * *

Your first day at Maze Corp.

Surely, _nothing can go wrong..._

Use the tools provided to you to navigate the office and make it through your first day without being terminated.
